🗺️ Google Maps Automation with Selenium
This project automates the testing of Google Maps functionalities using Selenium WebDriver, TestNG, and the Page Object Model design pattern.

🚀 Features
✅ Verify map loading

🔍 Search for a location (e.g., Bengaluru)

➕➖ Zoom in and out on the map

📍 Validate marker visibility

🧭 Test route search (e.g., New York to Boston)

📸 Capture screenshots on failure

📊 Generate ExtentReports

🛠️ Technologies Used
Java

Selenium WebDriver

TestNG

Page Object Model (POM)

ExtentReports

Maven
